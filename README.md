## 2. 학과 매칭 테스트

학과 매칭 테스트는 별도 페이지로 이동하지 않고 **화면 중앙 모달**에서 실행됩니다.

### 테스트 흐름

```text
CTA 버튼 클릭
  ↓
테스트 모달 오픈
  ↓
테스트 안내 화면
  ↓
10개 질문
  ↓
답변 선택
  ↓
학과별 점수 집계
  ↓
5개 학과 중 최종 학과 배정
  ↓
결과 화면
  ↓
다시 테스트 / 학과 자세히 보기 / 공유하기
```

### 동적 테스트 UI

테스트 화면의 내용은 JavaScript로 동적으로 생성됩니다.

#### 시작 화면

- 테스트 목적 안내
- `DEPARTMENT MATCHING`
- 정답은 없다는 안내
- 10개의 질문에 답하면 하나의 학과가 배정된다는 안내
- `테스트 시작하기` 버튼

#### 질문 화면

- 현재 질문 번호 `01 / 10` 형식
- 진행률 바
- `QUESTION 01` 형태의 질문 번호
- 질문 문구
- 선택지 버튼
- 선택 시 다음 질문으로 이동

#### 결과 화면

- `학과 배정 완료`
- 최종 배정 학과명
- 학과에 어울리는 이유
- 학과별 캐릭터 일러스트
- 학과 적합성 설명
- `다시 테스트하기`
- `학과 자세히 보기`
- `공유하기`

결과 캐릭터는 5개 학과별 SVG 일러스트와 연결됩니다.

## 3. 동적 인터랙션

정적인 정보 페이지가 아니라 사용자의 행동에 따라 화면이 변하도록 구성되어 있습니다.

### Scroll Reveal

`.reveal` 요소는 화면에 진입할 때 IntersectionObserver를 통해 `visible` 상태가 적용됩니다.

### Sticky Header

상단 헤더는 스크롤 중에도 고정되며, 스크롤 상태에 따라 시각적 변화가 적용됩니다.

### Scroll Progress

페이지 상단에 현재 스크롤 위치를 나타내는 진행률 표시가 있습니다.

### Department Accordion

학과를 클릭하면 해당 학과의 상세 영역이 펼쳐지고 기존에 열려 있던 학과는 닫힙니다.
`aria-expanded` 값도 함께 변경하여 상태를 반영합니다.

### Department Matching Modal

CTA를 클릭하면 별도의 페이지 이동 없이 테스트 모달이 열립니다.

- 배경 Backdrop
- 닫기 버튼
- ESC 키 닫기
- 모달 외부 클릭 처리
- Body 스크롤 잠금
- 테스트 단계별 콘텐츠 교체

### Test Progress

질문을 진행할수록 상단 진행률 바가 현재 진행 상황을 표시합니다.

### Dynamic Result

테스트 결과 콘텐츠는 사용자의 선택에 따라 동적으로 생성되며, 학과별 캐릭터 이미지와 설명이 함께 변경됩니다.

### Share Result

결과 화면의 `공유하기` 버튼은 다음 주소를 클립보드에 복사합니다.

```text
https://shkuhub.github.io/cyber-jorong-university/#departments
```

복사에 성공하면 버튼이 일시적으로 `링크 복사됨`으로 변경됩니다.
Clipboard API를 사용할 수 없는 환경에서는 fallback 복사 방식을 사용합니다.

결과 화면 자체가 동적으로 생성되기 때문에 MutationObserver를 사용하여 공유 버튼을 결과 화면에 추가합니다.

### Hover Interaction

학과, CTA, 버튼 등의 인터랙션에 미세한 이동·색상·그림자 변화를 적용해 실제 기관형 웹사이트의 인터랙션을 구현합니다.

## 5. 프로젝트 구조

```text
cyber-jorong-university/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── data.js
│   ├── main.js
│   ├── department-test-entry.js
│   └── department-test-card.js
├── assets/
│   └── characters/
│       ├── double-standard.svg

│       ├── life-consulting.svg
```

### 파일 역할

#### `index.html`

전체 랜딩페이지의 기본 HTML 구조와 섹션을 정의합니다.

#### `css/style.css`

전체 레이아웃, 색상, 타이포그래피, 반응형 스타일, 기본 UI와 테스트 모달 스타일을 담당합니다.

#### `js/data.js`

5개 학과, 공통과목, 3년 교육과정 등 콘텐츠 데이터를 관리합니다.

#### `js/main.js`

핵심 동적 기능을 담당합니다.

- 학과 목록 동적 렌더링
- 학과 아코디언
- 교육과정 동적 렌더링
- 10문항 학과 매칭 테스트
- 답변 점수 집계
- 테스트 모달 제어
- 결과 화면 생성
- 학과별 캐릭터 연결

#### `js/department-test-entry.js`

학과 매칭 CTA와 일부 보조 UI를 동적으로 구성합니다.

- 학과안내 바로 다음 위치에 CTA 생성
- 기존 입학안내 내부의 중복 CTA 제거
- 공통과목 카드 → 테이블 변환
- 결과 화면의 공유 버튼 생성
- 공유 링크 복사 처리
- 동적으로 추가된 요소의 reveal 처리

#### `js/department-test-card.js`

학과 매칭 CTA를 최종적으로 **독립적인 박스형 카드**로 스타일링합니다.

- Cream 배경
- 테두리
- 카드 Hover 효과
- Navy CTA 버튼
- 모바일 세로형 레이아웃

#### `assets/characters/`

5개 학과 결과 화면에 사용되는 캐릭터 SVG 일러스트입니다.

```javascript
  name: "학과명",

  description: "학과 상세 설명",

  career: "졸업 후 진로"
```

```javascript
{
  title: "과목명",
  desc: "교육내용"
}
```

```javascript
{
  code: "YEAR 1",
  title: "교육과정명",
  desc: "교육과정 설명",
  credit: "기초과정"
```

데스크톱, 태블릿, 모바일 환경을 고려합니다.

- 데스크톱: 넓은 콘텐츠 영역과 가로형 CTA 카드
- 태블릿: 콘텐츠 폭 및 간격 축소
- 모바일: 세로형 레이아웃과 전체 너비 CTA 버튼
- 교육과정 테이블: 작은 화면에서 가로 스크롤
- 테스트 모달: 화면 크기에 맞는 내부 스크롤

## 10. 콘텐츠 성격

사이트의 대학명, 학과명, 교육과정, 등록금 및 입학 관련 내용은 모두 패러디를 위한 가상의 설정입니다.

실제 교육기관의 입학, 등록, 학위, 교육과정 또는 기타 행정적 효력이 없습니다.
