# 싸이버 조롱대학교 — CYBER JORONG UNIVERSITY

실제 교육기관이 아닌 패러디형 대학 랜딩페이지입니다.

## 변경 사항

- 4년제 → **3년제 학사과정**
- Hero / About / Stats 문구를 3년제에 맞게 수정
- 교육과정을 **1학년 → 2학년 → 3학년** 구조로 재설계
- 학과 데이터와 커리큘럼 데이터를 HTML에서 분리
- CSS와 JavaScript를 별도 파일로 분리
- 학과 아코디언 및 스크롤 reveal 유지
- 반응형 모바일 레이아웃 유지

## 3년 교육과정

### 1학년 — 관찰과 자기합리화
사람의 말과 행동 사이에서 발생하는 모순을 관찰하고 기록합니다.

### 2학년 — 분석과 선택적 판단
이중잣대, 확증편향, 선택적 도덕성 등 인간 행동의 반복 패턴을 분석합니다.

### 3학년 — 실전 인간관찰 프로젝트
실제 사례를 분석하고 타인의 행동과 자신의 행동을 비교합니다.
마지막 연구 대상은 본인이 될 수 있습니다.

## GitHub Pages

GitHub 저장소에 업로드한 뒤:

`Settings → Pages → Deploy from a branch → main / root`

로 설정하면 정적 사이트로 배포할 수 있습니다.
