## 2. 학과 매칭 테스트

학과 매칭 테스트는 별도의 페이지로 이동하지 않고 **모달 방식**으로 실행됩니다.

### 테스트 흐름

```text
나에게 맞는 학과 찾아보기
        ↓
테스트 모달 오픈
        ↓
테스트 안내
        ↓
10개 질문
        ↓
선택 결과 집계
        ↓
5개 학과 중 1개 학과 배정
        ↓
학과 결과 + 캐릭터 + 설명
        ↓
다시 테스트 / 학과 자세히 보기 / 공유하기
```

### 테스트 질문

총 10개의 질문으로 구성되며, 각 답변에는 5개 학과 중 하나가 연결되어 있습니다.

질문은 약속, SNS, 회의, 실수, 타인의 지적, 연애상담, 소비, 원칙, 성취, 온라인 정보 등 일상적인 상황을 기반으로 합니다.

테스트 결과는 사용자가 선택한 답변의 학과별 점수를 집계하여 가장 높은 학과를 최종 결과로 보여주는 방식입니다.

### 결과 화면

결과 화면에는 다음 정보가 표시됩니다.

- `학과 배정 완료`
- 배정된 학과명
- 학과에 어울리는 이유
- 학과별 캐릭터 일러스트
- 학과 적합성 설명
- 다시 테스트하기
- 학과 자세히 보기
- 공유하기

### 공유하기

결과 화면의 **공유하기** 버튼은 다음 고정 주소를 클립보드에 복사합니다.

```text
https://shkuhub.github.io/cyber-jorong-university/#departments
```

복사 성공 시 버튼 문구가 일시적으로 `링크 복사됨`으로 변경됩니다.
Clipboard API를 사용할 수 없는 환경에서는 기본 복사 방식으로 대체합니다.

## 5. 데이터 구조

학과 데이터는 `js/data.js`의 `departments` 배열에서 관리합니다.

각 학과는 다음 구조를 가집니다.

```javascript
{
  name: "학과명",
  subtitle: "학과 한줄 소개",
  description: "학과 상세 설명",
  courses: ["주요과목 1", "주요과목 2"],
  career: "졸업 후 진로"
}
```

공통과목은 다음 구조입니다.

```javascript
{
  title: "과목명",
  desc: "교육내용"
}
```

3년 교육과정은 다음 구조입니다.

```javascript
{
  code: "YEAR 1",
  title: "교육과정명",
  desc: "교육과정 설명",
  credit: "기초과정"
}
```
